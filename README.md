
# UrbanNest – Data Foundation and Baseline Regression

## Project Overview

This project focuses on building a reliable data foundation for house price prediction using the Ames Housing Dataset.

The main objectives are to:
- Explore and understand the housing dataset.
- Identify and handle missing values.
- Clean and preprocess the dataset.
- Convert categorical features into numerical features.
- Build a baseline Linear Regression model.
- Evaluate model performance using MAE, RMSE, and R².

## Dataset Source

The project uses the Ames Housing Dataset.

**Dataset:** [Ames Housing Dataset – Kaggle](https://www.kaggle.com/datasets/preathm/ames-housing-dataset)

The dataset contains information about residential properties, including:
- Building characteristics
- Property quality and condition
- Basement and garage details
- Neighborhood information
- Sale prices

**Target Variable:** `SalePrice`

## Data Cleaning and Preprocessing

The original dataset contains missing values in several numerical and categorical columns.

The preprocessing steps include:

1. Removing rows with missing target values (`SalePrice`).
2. Removing identifier columns (`Order` and `PID`) from model features.
3. Replacing structural missing categorical values with `None`.
4. Replacing structural missing numerical values with `0`.
5. Splitting the dataset into training and testing sets using an 80/20 split.
6. Calculating numerical medians using training rows only.
7. Calculating categorical modes using training rows only.
8. Applying these training-set statistics to both training and testing rows.
9. Applying One-Hot Encoding to categorical features.
10. Saving the processed dataset as `cleaned_ames_housing.csv`.

### Data Leakage Prevention

To prevent data leakage, median and mode values for the cleaned CSV are calculated exclusively from the training rows.

The calculated training-set statistics are then applied to both training and testing rows.

This ensures that information from the test set does not influence the imputation statistics.

The baseline model also uses a separate Scikit-learn preprocessing pipeline. Its numerical and categorical imputers and One-Hot Encoder are fitted on training data only.

## Baseline Regression Model

A Linear Regression algorithm is used to establish a baseline for predicting residential property sale prices.

### Model Workflow

1. Load the original dataset.
2. Handle structural missing values.
3. Split the data into training and testing sets.
4. Identify numerical and categorical features.
5. Apply median imputation to numerical features.
6. Apply most-frequent imputation to categorical features.
7. Encode categorical features using One-Hot Encoding.
8. Train the Linear Regression model.
9. Generate predictions on the test set.
10. Evaluate model performance.

### Model Evaluation Results

The model was evaluated using three standard regression metrics.

| Evaluation Metric | Result |
|---|---:|
| Mean Absolute Error (MAE) | $17,309.70 |
| Root Mean Squared Error (RMSE) | $29,633.80 |
| R² Score | 0.8905 |

### Evaluation Summary

- **MAE:** The average absolute difference between actual and predicted sale prices is approximately $17,309.70.
- **RMSE:** The root mean squared prediction error is $29,633.80.
- **R² Score:** The model explains approximately 89.05% of the variation in house sale prices.

These results establish a baseline for future improvements using more advanced regression algorithms.
